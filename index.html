Come pubblicare il tuo Editor su GitHub Pages

Questo intero editor è contenuto in un unico file (`index.html`) e non richiede alcun server o database. Puoi metterlo online gratis in 2 minuti:

1. Crea un Repository su GitHub

Accedi al tuo account GitHub, clicca su New Repository, chiamalo ad esempio mio-editor-pdf e impostalo come Public.

2. Carica il file index.html

Salva il codice di questa pagina sul tuo computer con il nome esatto index.html e caricalo nel repository cliccando su Add file → Upload files.

3. Attiva GitHub Pages

Vai su Settings → Pages nel tuo repository, sotto Branch seleziona main e clicca Save. Dopo 60 secondi avrai il tuo link pubblico gratuito!
